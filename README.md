# Bright C Nwogu — React Portfolio

A responsive personal portfolio built with React, Vite, and custom CSS.

## Run locally

1. Install Node.js (LTS).
2. Extract this project folder.
3. Open the folder in VS Code.
4. Open the terminal in VS Code and run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local address shown in the terminal (usually `http://localhost:5173`).

## Before publishing

Update the placeholders in `src/App.jsx`:
- Replace `your.email@example.com` with your professional email.
- Replace the GitHub URL with your GitHub profile.
- Replace the LinkedIn URL with your LinkedIn profile.
- Add your preferred profile photo if you want one (the current hero uses a code illustration).

Review the skills list so it accurately reflects the technologies you can confidently work with. The Abia Transport project is labelled as a concept/in-development project rather than a completed product.

## Build for deployment

```bash
npm run build
```

The production-ready website will be generated in the `dist` folder. You can deploy that folder using a static hosting provider such as Vercel or Netlify.
